# Situs Gontor Cup Antar Kampus 1448/2026

Repositori ini **hanya berisi hasil paket** yang dilayani ke pengunjung.
Berkas sumbernya (skrip pembangun halaman, PDF juklak asli, aset desain, dan
kode Google Apps Script) sengaja **tidak** disimpan di sini, sebab kode Apps
Script memuat sandi panel admin.

Isinya dihasilkan oleh `tools/siapkan_rilis.py` di folder proyek, lalu
di-`git push` ke sini. Jangan menyunting berkas di repositori ini secara
langsung, kecuali satu baris `API` di `assets/js/config.js`; perubahan lain
akan tertimpa pada paket berikutnya.

Halaman admin ada di `/admin/` dan dijaga sandi.
